Abstract

Recent data-driven visual odometry models achieve strong zero-shot generalization using large-scale synthetic training data, but they can still struggle in novel domains and often require costly customization. SF-VO is a self-supervised collect-then-adapt framework that specializes an off-the-shelf visual odometry model to a target domain using only a few selected episodes and a minimal set of learnable parameters. It builds and curates an episodic memory bank using pose consistency and motion statistics, then optimizes compact adapters with a self-supervised multi-interval pose-consistency objective.
